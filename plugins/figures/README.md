# Figures

Quartz v5 transformer for ordinary images, legacy colon captions,
`{{caption}}` directives, and accessible `{{compare}}` before and after
figures. It also supplies the figure carousel used by the otton.org map plugin.

Install from `https://github.com/djotto/quartz-plugins` with subdirectory
`plugins/figures` and plugin name `figures`. Run it after
`@quartz-community/obsidian-flavored-markdown`.
