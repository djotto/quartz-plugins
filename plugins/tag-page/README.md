# Tag Page

Quartz v5 tag pages with the otton.org list layout and Explorer sorting.

The package includes its own list renderer, styles, and sorting logic so it can
be installed independently of the local Folder Page plugin. The source was
copied from that plugin during extraction; keep their shared behaviour in sync
until Folder Page is migrated.

Install from `https://github.com/djotto/quartz-plugins` with subdirectory
`plugins/tag-page` and plugin name `tag-page`. This replaces the default
`@quartz-community/tag-page` plugin.
