# Table of Contents

A Quartz v5 table of contents plugin with Quartz v4-compatible navigation behaviour.

It provides both a Markdown transformer and a `TableOfContents` component, with modern and legacy
layouts, active-heading tracking, accessible collapse controls, and overflow indicators.

## Options

- `maxDepth`: deepest heading level to include.
- `minEntries`: minimum threshold before a table of contents is emitted.
- `showByDefault`: whether pages show a table of contents unless frontmatter disables it.
- `collapseByDefault`: whether the table of contents starts collapsed.
- `layout`: `modern` or `legacy` component styling.
