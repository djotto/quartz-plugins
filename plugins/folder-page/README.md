# Folder Page

Quartz v5 folder pages with the otton.org list layout, Explorer sorting,
and frontmatter `include` tags.

Install from `https://github.com/djotto/quartz-plugins` with subdirectory
`plugins/folder-page` and plugin name `folder-page`. This replaces the
default `@quartz-community/folder-page` plugin.

This plugin and Tag Page each include their own list renderer, styles, and
sorting logic so each can be installed independently. Keep shared behaviour
in sync when updating either package.
